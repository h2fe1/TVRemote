# 正在播放条 · Android 原生方向

设计稿：[总览](android-now-playing-directions.png) · [A](option-a.png) · [B](option-b.png) · [C](option-c.png)

Android 17 参考：[原生媒体播放器实机截图](android-17-native-reference.png) · [方向 D](option-d.png)

范围：App 内、遥控器页、触控板上方。不涉及通知栏 / 锁屏的 MediaSession 通知（那是另一条实现路径，见文末）。

## 现状

1.1.0 里的条是 iOS 风：44dp 封面 + 标题/副标题 + 时间进度 + 右侧播放键，玻璃渐变大圆角。信息够，但层级和控件排列更像 iOS 的媒体小组件。

## 三个方向

| | A · Material 3 迷你播放器（推荐） | B · Android 13 媒体通知卡 | C · 系统媒体胶囊 |
|---|---|---|---|
| 高度 | 64dp | 84dp | 48dp |
| 封面 | 40dp | 56dp | 32dp |
| 信息 | 标题、副标题、底部 2dp 进度线 | 标题、副标题、时间进度、上一集 / 播放 / 下一集 | 标题、副标题、播放键 |
| 空间影响 | 触控板几乎不缩 | 最高，小屏会压缩触控板 | 最小 |
| 交互 | 点播放键切换；点条身展开完整播放器 | 全部操作在条上完成 | 只做状态提示 |
| 适合 | 日常遥控，保持遥控器手感 | 看剧时想直接看到进度、切集 | 只想提示“在播什么” |

### A · Material 3 迷你播放器（推荐）

- 单行 + 底部 2dp 进度线，是 Android 音乐类 App 最常见的 in-app mini player 结构。
- 默认态最省空间，触控板和三个圆键的位置几乎不变。
- 点条身展开成完整的播放器（可以直接复用 B 的布局），这样“看进度 / 切集”的需求放在展开态里，不常驻占空间。
- 风险：折叠态没有时间数字，只有进度线。

### B · Android 13 媒体通知卡

- 最接近 Android 系统媒体通知：封面更大、有 `24:26 / -20:43`、上一集 / 播放 / 下一集。
- 信息最全，不用展开就能操作。
- 代价是高度 84dp，比现在多约 20dp；在矮屏上要压缩触控板，横屏手机基本放不下。
- 配色可跟封面取色（Material You），也可以统一用 App 的蓝色。

### C · 系统媒体胶囊

- 48dp 高、全圆角，只保留封面、标题和播放键，接近系统 QS / 媒体输出条的存在感。
- 最不抢遥控器的视觉，但完全没有进度和时间。
- 适合“知道在播什么就行”的场景。

## 建议

先做 **A**，并把 B 作为 A 的展开态：

- 默认：64dp mini player，触控板不受影响。
- 点条身：向上展开成 B 的完整卡片（封面、进度、上一集 / 播放 / 下一集）。
- 再点空白或下滑：收回 A。
- 颜色先用 App 现有蓝色；之后可选做封面取色。

这样既保留了 Android 原生的层级，也不会让常驻区域变高。

## 实现备注

- 数据仍用现有的 `NowPlayingInfo` + `_iMC`，不需要新权限。
- 无内容 / 电视不上报时整条隐藏，不占位。
- 高度变化时触控板自适应收缩，三个圆键保持圆形（当前 1.1.0 已经这么做）。
- 横屏手机高度不足时继续隐藏；平板横屏可显示。
- 若选 B，上一集 / 下一集走 `MediaControlCommand.PreviousTrack / NextTrack`；若更想要 ±15 秒，改成 `SkipBy`。

## Android 17 的原生样式（QPR1 Beta 3）

参考图：[android-17-native-reference.png](android-17-native-reference.png)

2026 年 5 月的 Android 17 QPR1 Beta 3 把媒体控制从「整块卡片左右滑动切换」改成了「主卡片 + 两侧会话胶囊」：

- 当前会话是一张**全幅封面铺底**的大圆角卡片，封面上面压深色遮罩保证文字可读。
- 播放 / 暂停是**大号胶囊按钮**，颜色跟随封面动态取色（Material You）。
- 标题、作者直接压在封面上，底部一排是循环、进度、下一首 / 倍速 / 收藏等，按 App 能力增减。
- 其他可恢复的媒体会话缩成左右两条竖向胶囊，点按即可切换。
- 这是**系统 UI**：App 只能通过 `MediaSession` 让通知栏 / 锁屏 / QS 渲染它，不能把这张卡直接嵌进自己的页面。

参考来源：[Android Authority（2026-05-21）](https://www.androidauthority.com/android-17-new-media-app-switcher-ui-3669602/) · [9to5Google（2026-05-20）](https://9to5google.com/2026/05/20/android-17s-media-player-carousel-gets-a-card-based-redesign-in-qpr1-beta-3/) · [IT之家（2026-05-22）](https://www.ithome.com/0/953/811.htm)

### 方向 D · 把 Android 17 语言移植到 App 内

参考图：[option-d.png](option-d.png)

- 114dp，全幅封面 + 深色遮罩 + 约 28dp 大圆角。
- 大号胶囊播放键，颜色跟封面取色（截图里是封面里的粉色）。
- 标题 / 副标题压在封面上，底部放上一集、进度、下一集。
- 视觉最接近 Android 17，但也是四个方案里最高的：会明显压缩触控板，小屏和横屏都不太适合常驻。

### D2 · 当前实现

最终界面见：[docs/screenshots/remote.png](../screenshots/remote.png)（早期中间稿是 [option-d2.png](option-d2.png)）

- 136dp，全幅封面 + 深色遮罩 + 28dp 大圆角；上边缘贴在右上角截图按钮下方，宽度与下方遥控器一致（左右 18dp，最大 420dp）。
- 上方标题 / 副标题；进度条左侧当前时间、右侧剩余时间。
- 进度条下方一排四个 **44dp 等大圆形按钮**：后退 15 秒、播放 / 暂停、前进 15 秒、静音（最右）。
- 播放键用 App 蓝色实心；静音未开启是半透明圈，开启后白底深色图标。
- ±15 秒走 `_mcc` 的 `SkipBy`（`_skpS` = ±15.0）。
- 静音走 `_mcc` 的 GetVolume / SetVolume：读当前音量 → 设为 0 → 再点恢复。
- 卡片在页面底部，媒体条在顶部；屏幕矮时触控板自适应收缩，手机横屏高度不足时继续隐藏。

## 如果指的是系统通知栏 / 锁屏

那是另一种做法：`MediaSession` + `MediaStyle` 通知，系统会把它显示在通知栏、锁屏和 QS 媒体区，样式由 Android 版本决定，App 内不一定要有这条。需要的话我可以单独出一版这个方向的设计和取舍。

## 锁屏 / 通知栏

- 通过 `MediaSession` + `MediaStyle` 前台服务发布，系统渲染原生媒体卡；不是把 App 内这条 Compose 卡画到锁屏上。
- 显示条件：已连接 + 有 NowPlaying + 播放/暂停 + 非 Asleep / Screensaver。
- 控件：播放 / 暂停、±15 秒、静音；点击标题通过 `contentIntent` / `sessionActivity` 回到 `MainActivity`，保留当前遥控器页面。
- 服务在连接期间常驻：有播放时是媒体卡；无播放时降级为低优先级「已连接」通知（`VISIBILITY_SECRET`，锁屏不可见），保证在其他手机 App / 锁屏状态下切换电视 App 也能重新拉起媒体卡。
- 电视回主界面、休眠或断开连接后，媒体卡消失；断开连接时服务停止。
